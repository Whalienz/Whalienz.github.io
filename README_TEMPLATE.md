# Portfolio Template - Markdown Version

This is a clean Markdown portfolio template converted from Jekyll.

## How to Use

1. Edit `portfolio.md` to customize your portfolio
2. Replace placeholder content with your own information
3. Update image URLs and links
4. Deploy to GitHub Pages or any static hosting

## Features

- ✨ Clean Markdown syntax
- 📱 Responsive design (via CSS)
- 🎨 Custom styling with embedded HTML when needed
- 📊 Projects showcase
- 💼 Skills section
- 📧 Contact information
- 🔗 Social media links

## Customization

Edit these sections in `portfolio.md`:
- Hero section (name, title, description)
- About section (bio, stats)
- Projects (title, description, tags, links)
- Skills (technologies you know)
- Contact info (email, phone, social media)

## File Structure

```
.
├── portfolio.md          # Main portfolio file (edit this!)
├── styles.css            # Styling
├── script.js             # JavaScript functionality
└── images/              # Your images
```
