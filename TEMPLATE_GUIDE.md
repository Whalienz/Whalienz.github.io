# Pure Markdown Portfolio Template

## 📋 Template Structure

This is a **pure Markdown template** without any HTML or CSS.

### Features
- ✅ 100% Markdown syntax
- ✅ No HTML tags
- ✅ No CSS files
- ✅ Works with any Markdown renderer
- ✅ GitHub-flavored Markdown compatible
- ✅ Easy to customize

---

## 🎯 How to Use This Template

### 1. Edit Content
Open `portfolio-pure.md` and replace:
- Your name and title
- Project descriptions
- Skills list
- Contact information
- Social media links

### 2. Replace Images
Change image URLs in the format:
```markdown
![Alt text](your-image-url)
```

### 3. Update Links
Replace `#` with actual URLs:
```markdown
[Link Text](https://your-url.com)
```

## 📝 Markdown Syntax Guide

### Headers
```markdown
# H1 - Main Title
## H2 - Section Title
### H3 - Subsection Title
```

### Text Formatting
```markdown
**Bold text**
*Italic text*
`Code/Tag`
> Quote
```

### Lists
```markdown
- Bullet point
- Another item

1. Numbered item
2. Another item
```

### Links & Images
```markdown
[Link text](url)
![Image alt text](image-url)
```

### Tables
```markdown
| Column 1 | Column 2 |
|----------|----------|
| Data 1   | Data 2   |
```

### Horizontal Line
```markdown
---
```

## 🎨 Customization Guide

### Adding New Project

```markdown
### X. Project Name

![Project Image](image-url)

Project description here

**Technologies:** `Tech1` `Tech2` `Tech3`

🔗 [Code](github-url) | [Demo](demo-url)

---
```

### Adding New Skill Category

```markdown
### Category Name
- Skill 1
- Skill 2
- Skill 3
```

### Changing Emojis

Replace emojis with your preferred ones:
- 👋 💼 🛠️ 📖 📞 📧 📱 📍 🌐
- 🔗 ✅ ❌ 🎯 📝 🎨 ⚡ 🚀 💡

When creating your portfolio, customize these sections:

## 🚀 Deployment Options

### GitHub
1. Rename `portfolio-pure.md` to `README.md`
2. Push to GitHub
3. Will display automatically on your repo

### GitHub Pages
1. Rename to `index.md`
2. Enable GitHub Pages in repo settings
3. Choose a theme (optional)

### GitLab/Bitbucket
Same as GitHub - supports Markdown rendering

### Notion/Obsidian
Import the `.md` file directly

## ✨ Tips

1. **Keep it simple** - Markdown is meant to be readable
2. **Use emojis sparingly** - They add personality but don't overdo it
3. **Test rendering** - Preview on different platforms
4. **Add images** - Visual content makes it more engaging
5. **Update regularly** - Keep your projects and skills current
